# 谐不压怔！一日麻！v0.1.0

Fin 的四人连线日麻作品。此为可下载的浏览器游戏，包含本机房间服务。

## 先看这里

- 需要四位真人，没有电脑对手。
- 一台电脑作为主机；所有玩家通过浏览器加入。
- 主机首次运行前，安装 Node.js 24 LTS：https://nodejs.org/en/download
- 主机安装好 Node.js 后，运行下载版不需要 npm install，也不需要 ChatGPT 或 Cloudflare 账号。
- 支持本机与同一局域网游玩。不能把 localhost 链接发给异地朋友。
- 游戏不涉及金钱。规则是核心日麻实现，尚未覆盖完整比赛规则。

## 三步开桌

1. **完整解压 ZIP**，不要在压缩包预览窗口中运行。
2. 主机运行启动文件：
   - Windows：双击 `start-windows.bat`。
   - macOS：双击 `start-macos.command`。若系统不允许直接运行，在终端进入文件夹后执行 `sh start-macos.command`。
   - Linux：在终端进入文件夹后执行 `sh start-linux.sh`。
3. 保持终端窗口开启，复制它显示的**局域网地址**到浏览器。主机从这个地址建房，再把带房号的链接分享给同一 Wi-Fi／局域网内的朋友。四人到齐后，房主点「开始东一局」。

若系统询问网络访问，局域网模式需要允许该程序访问当前私人网络。路由器的访客隔离可能阻止设备互相连接。手机也必须连接同一网络。

只在自己电脑体验界面，可以打开终端显示的本机地址；测试四个座位时使用四个独立浏览器配置或不同浏览器。同一浏览器的普通标签共用座位身份。

## 操作

- 轮到你时点「摸牌」。选中一张手牌，再点「打出」。
- 符合条件时会出现立直、吃／碰／杠、荣和、自摸按钮。
- 鸣牌窗口约 12 秒，不操作按过处理；需有玩家页面保持连接以推进超时。
- 每人起始 25,000 点，进行东风战。房主负责下一局及原房再开。
- 关闭终端会断开服务。重新启动同一文件夹，可恢复已保存的房间。

## 数据与连接

牌局只写入主机的 `data/` 文件夹；玩家座位凭据留在各自浏览器的本地存储中。请勿分享 `data/` 或把它上传 GitHub。清除浏览器数据后，旧座位不能自动找回；此版尚无房主踢人、断线替补或账号恢复功能。

使用 `node server.mjs` 只允许本机连接；启动文件使用的 `node server.mjs --lan` 允许局域网连接。默认端口 3000，可用 `PORT` 环境变量更换。单个数据文件夹只能运行一个服务进程。

异地朋友可使用现有在线版：https://yique-mahjong-2026.ghwsocio918.chatgpt.site
下载包不会连接在线版的房间或数据库。

## 当前范围

支持四人房、摸打、吃碰杠、立直、部分役种与计分、宝牌、结算及续局。没有电脑对战、公开匹配大厅或原生桌面安装器。未验证为完整竞技规则引擎，边界计分、特殊役种和特殊流局仍需继续完善。
