# v0.1.1 — 振听与房间同步维护

- 自舍振听检查整组和牌等待，避免舍过另一张等待牌后仍能荣和。
- 放弃荣和、超时或选择其他鸣牌均设置漏和振听；立直后的漏和振听保留至本局结束。
- 房间同步按玩家身份和数据库版本接收状态，防止旧轮询覆盖入座或刚完成的操作；轮询不再重叠，切换身份时取消旧请求。
- 不存在的房间停止轮询，并提供重新连接和返回首页；断线时显示重试提示。
- 规则和同步回归检查纳入下载版构建流程。在线版与下载版共用此次修复。

# v0.1.0 — 首个可下载作品版本

《谐不压怔！一日麻！》是 Fin 的四人连线日麻作品。

## 下载什么

- **yiri-mahjong-v0.1.0-portable.zip**：已构建的游戏、本机房间服务、Windows／macOS／Linux 启动文件。主机安装 Node.js 24 LTS 后解压运行，无需安装开发依赖。
- **yiri-mahjong-v0.1.0-source.zip**：源码、作品说明、构建脚本与测试。
- **SHA256SUMS.txt**：两个 ZIP 的 SHA-256 校验值。

## 本版本

- 保留原有四人房间、日麻牌桌与东风战流程。
- 新增独立本机服务，供同一局域网的四位真人游玩。
- 牌局保存于主机 data 目录，支持服务重启后恢复。
- 包含启动说明、依赖许可声明及 GitHub 自动打包配置。
- 修复局域网 HTTP 页面没有安全剪贴板接口时的分享降级处理。
- 字体使用本机可用字体与中文回退字体，不依赖构建时下载 Google Fonts。

## 已知范围

需要四位真人；不含电脑对手。此下载包不是免运行环境的 EXE／APP 安装器。当前为核心规则原型，不能视为完整比赛级日麻引擎。尚无断线替补、账号恢复、房主踢人及公网服务的运维配置。

此版本验证了本机服务的建房、并发入座、四席权限、完整一局推进、数据恢复与文件访问边界；未在实体 Windows／macOS 电脑上执行启动文件，也未执行浏览器端到端测试。
